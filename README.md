# Zib-Zib sinth

Веб-синтезатор по макету Figma «alien». HTML, CSS, JavaScript и Tone.js.

## Запуск

Звук загружается только через локальный сервер: расширение Live Server в VS Code или `npx serve .` в этой папке.

## Файлы

```
index.html                  разметка экранов
stylesheets/style.css       подключает остальные стили
stylesheets/reset.css       сброс стилей браузера
stylesheets/fonts.css       шрифты
stylesheets/layout.css      размеры, цвета и эффекты из макета
stylesheets/animation.css   анимации и переходы
stylesheets/adaptive.css    режим уменьшенного движения
javascripts/scripts.js      экраны, синты и звук
images/                     пришелец, иконки из макета, шум, favicon
fonts/                      Desyatiy Regular, Desyatiy Light, TOYZ
sounds/zibzib.mp3           голос Zib-Zib
```
